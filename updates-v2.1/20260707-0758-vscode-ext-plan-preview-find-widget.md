# 20260707-0758 — Enable Cmd+F / Ctrl+F in the Claude Code plan-preview webview + extract its CSS

**Affects** : v2.1 devcontainers where the Claude Code VS Code extension
opens a plan in its `claudePlanPreview` webview but the native find
widget (Cmd+F / Ctrl+F) does not respond.

**Symptom** : opening a plan file from Plan mode gives a rendered
markdown viewer, but hitting Cmd+F does nothing — no find-bar, no
in-page search. Users have to scroll manually.

**Cause** : the extension calls `vscode.window.createWebviewPanel(...)`
with `{enableScripts:!0, retainContextWhenHidden:!0}` but does NOT set
`enableFindWidget`, which defaults to `false`. VS Code webviews expose
that documented option — flipping it to `true` branches the native
find-bar with the same Cmd+F shortcut users expect elsewhere.

**Bonus** : the plan-preview CSS (~4.9 KB) is inlined in the minified
extension bundle. This update also extracts it as a standalone file
(`plan-viewer.css`) so it can be inspected or reused outside the
extension. The rendered HTML is generated by the bundled [`marked`](https://github.com/markedjs/marked)
markdown parser (default output, no Anthropic customization) — only
the CSS is Anthropic-custom.

## Manual how-to

Two new scripts + a companion `extracted/` directory. Both trees
(`.devcontainer/` dogfood and `templates/v2/` shipped template) get
the same additions.

### File 1 — `.devcontainer/claude/vscode-ext-patchs/plan-preview-find-widget.py`

New patch script following the same shape as `user-action-observer.py`
and `icon-fix-open-in-current-panel.py` :

- `from _common import ...` for banner + `resolve_ext_dir` + `check_files`
- Regex anchored on the stable string `"claudePlanPreview"` (webview
  viewType — part of the public identity, unlikely to change across
  minor bumps)
- Backreferences capture the minified `require("vscode")` alias
  (currently `BK0`), the title parameter (`K`), the viewColumn
  parameter (`N`) — patch survives version bumps that rename the
  bindings
- Idempotence via presence check for `enableFindWidget:!0` within
  300 chars after the anchor
- Exit 1 with red banner on regex miss ; `run-all.sh` stays green
  regardless (cosmetic patch)

### File 2 — `.devcontainer/claude/vscode-ext-patchs/extracted/plan-viewer.css`

Byte-for-byte snapshot of the `<style>` block inside `NK0` in
`extension.js` (v2.1.145). VS Code theme variables verbatim so the
file adapts to any theme when reused elsewhere. Covers markdown output
+ Anthropic's custom commenting UI (`mark`, `.comment-indicator`,
`#comment-btn`, `#comment-input`, `#comment-banner`).

### File 3 — `.devcontainer/claude/vscode-ext-patchs/extracted/README.md`

Documents the extraction : source version, the fact that HTML is
produced by `marked` (with `npm i marked` reproduction recipe), the
list of VS Code theme variables consumed, and the webview `postMessage`
protocol.

### Files 4-6 — `templates/v2/claude/vscode-ext-patchs/`

Same three files, same content — the template mirror keeps downstream
projects generated from `templates/v2/` in sync with the dogfood tree.

### Commit

`````bash
git add \
  .devcontainer/claude/vscode-ext-patchs/plan-preview-find-widget.py \
  .devcontainer/claude/vscode-ext-patchs/extracted/plan-viewer.css \
  .devcontainer/claude/vscode-ext-patchs/extracted/README.md \
  templates/v2/claude/vscode-ext-patchs/plan-preview-find-widget.py \
  templates/v2/claude/vscode-ext-patchs/extracted/plan-viewer.css \
  templates/v2/claude/vscode-ext-patchs/extracted/README.md

git commit -m "feat(vscode-ext): enable Cmd+F in plan-preview webview + extract its CSS"
`````

### Apply the patch (existing devcontainer, no rebuild required)

The `run-all.sh` orchestrator picks the new script automatically at the
next container boot. To apply immediately without rebuilding :

`````bash
python3 .devcontainer/claude/vscode-ext-patchs/plan-preview-find-widget.py
`````

Then reload the VS Code window (palette → `Developer: Reload Window`)
so the extension reloads the patched bundle from disk.

## Rollback

Remove the six files and revert the extension.js change :

`````bash
rm .devcontainer/claude/vscode-ext-patchs/plan-preview-find-widget.py
rm -r .devcontainer/claude/vscode-ext-patchs/extracted
rm templates/v2/claude/vscode-ext-patchs/plan-preview-find-widget.py
rm -r templates/v2/claude/vscode-ext-patchs/extracted

sed -i 's/,enableFindWidget:!0//' \
  ~/.vscode-server/extensions/anthropic.claude-code-*/extension.js

git revert <commit-hash>
`````

Reload the VS Code window to pick the reverted bundle.
