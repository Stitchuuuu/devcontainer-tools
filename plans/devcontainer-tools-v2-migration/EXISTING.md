## v1.3 placeholders (going away in v2)

v2 replaces 11 of these with shell variable expansion
(`${DC_PROJECT:-default}` etc.) resolved at runtime from `.env`.
Only `{{PROJECT_ID}}`, `{{PROJECT_DISPLAY_NAME}}`, `{{TIMEZONE}}`
survive in v2. See [SCOPE.md](SCOPE.md) §"Templating model".

v1.3 placeholders (deprecated in v2) :

- `{{PROJECT_ID}}` — **kept** (used in `.env.example` default)
- `{{PROJECT_DISPLAY_NAME}}` — **kept** (used in `devcontainer.json`)
- `{{TIMEZONE}}` — **kept** (used in `.env.example` default)
- `{{DB_HOST}}` / `{{DB_PORT}}` / `{{DB_NAME}}` / `{{DB_USER}}` /
  `{{DB_PASS}}` — **dropped** (no DB templating in v2 ; users
  edit `.env` directly)
- `{{NETWORK_NAME}}` + `#__NETWORK__` marker — **dropped** (v2
  compose uses `${EXTRA_NETWORK:-}` or omits the section)
- `{{EXTENSIONS_JSON}}` — **dropped** (v2 devcontainer.json has
  a fixed default list ; users edit post-install)
- `{{CREDS_VOLUME_LINE}}` — **dropped** (v2 uses
  `${CLAUDE_CREDS_VOLUME:-claude-creds-${DC_PROJECT}}`)
- `{{FIREWALL_ALLOWED_LINE}}` — **dropped** (v2 .env handles directly)
- `{{LANG_DOMAINS}}` — **dropped** (v2 uses `firewall/domains.d/`
  per ecosystem, auto-generated by `/scan-deps`)
